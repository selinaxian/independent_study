# v7：真实价格事件作为 STDP 教师信号

2026-10-28，于金融实验运行前固定。本轮解决用户最新要求：特征领先/滞后真实价格事件，直接改变该特征突触。原v6未完成，暂缓；原v1—v5保持不变。价格事件教师不同于原论文自行放电的输出神经元；本版不是纯无监督学习、不是原文完整复现。沿用brainstorming的机制梳理与planning-with-files的阶段记录，依据用户自主执行授权实施。

## 数据、事件与输入

- 只读v1已选真实合约的43440分钟底表及12项因果特征；复用v2的23折40日训练/10日验证/5包日期预测日历。事件样本新生成，因此不是原15900个收益窗口，不能把IC直接比较。
- 价格事件：分钟t收盘可知的绝对对数收益 `abs(log(C_t/C_{t-1}))*10000` 超过本折训练期95%分位，且此前连续5分钟均未超过同一阈值。连续行情时段内定义，不跨午休、缺口、日或合约；这是“静默后阈值突破”的操作定义，不等于市场全部极端风险。
- 特征脉冲：每项特征训练期20%/80%分位，分别向下穿越低阈值、向上穿越高阈值时各放一次电。两通道是相对阈值的低/高事件，不是浮点正负；零变化不反复放电，首个有效值不凭空穿越。12×2=24通道，直接连接单个预警单元，无隐藏层、无8步幅度延迟编码。
- 训练教师脉冲仅在当时已发生的价格事件上触发。价格/特征的同时变化不算领先。训练期事件虽可用于学习，预测时未来事件不进入输入或权重。

## STDP 与输出

- 按真实分钟顺序逐步更新。对每条连接i，`pre_trace=sum(exp(-d/3)*s_i[t-d],d=1..5)`，post_trace同理。`dw=.01*(1-w)*event[t]*pre_trace - .01*w*s_i[t]*post_trace`，w限于[0,1]。初始0.5，训练3遍；时段边界清迹，权重保留。每折重新训练，不承接上折权重。
- 正向顺序加权，反向顺序减权，零时差不更新。这是有界、权重依赖的成对STDP，后突触由价格教师驱动，不加入监督梯度或事后翻转。
- 不声称该规则会自动压低所有无用特征：经常放电、事件持续与共同驱动都可能造成偶合。未发生事件本身不产生负向更新；领先相关也不证明因果。这些通过对照和独立预测检验，而非修改结果措辞处理。
- 输出为24路脉冲最近5分钟的漏积分电位 `V_t=sum_i w_i sum(d=0..4) exp(-d/3)*s_i[t-d]`；每次预测为独立5分钟积分窗，不跨时段。不额外拟合Ridge替代主模型权重；V是风险预警分数，未校准为概率。验证期V的80%分位提供告警门槛，严格大于门槛才告警。当前原型是STDP突触+漏积分输出，未实现自由运行并发放后重置的LIF动力学，不将阈值标志冒称完整LIF网络。

## 滚动检验和对照

- 主预测问题：t时刻已知最近5分钟没有阈值突破，未来1—5分钟是否出现上述事件。必须具备完整特征历史、过去5分钟与未来5分钟同一时段。排除已处于事件中的时点是因果过滤，只用截至t信息。训练、验证和预测各自只使用其日期内的标签。
- 对照：同输入同积分但不训练的等权0.5；在每个训练半日内循环错开教师事件（偏移至少10分钟，保留计数，3固定种子）；当前5分钟实现波动；同24路积分输入的监督Ridge事件分数（训练拟合、验证Brier选择alpha，不宣称校准概率）。所有告警门槛仅使用过去验证分数，预测期不更新。
- 报告每个决策时点的实际事件比例、AUC、AP、精确率、覆盖率、召回；另按独立事件记录是否有此前1—5分钟的告警及最早告警提前量。成功告警的提前量不能忽略漏报；输出事件覆盖率作为分母。整日配对5日块重采样给AP/AUC差区间，23折样本按时间拼接；分月及分折另列，跨折阈值/校准会影响合并指标。
- 对每个特征保留训练前后权重、正向/反向配对贡献和预测期领先/滞后配对计数。错配教师为诊断对照，不是完美零假设（保留日内非平稳性）。权重大不直接等于特征重要性，需结合活动频率及样本外效用。
- 合成例明确构造领先2分钟、滞后2分钟、同时、无事件关系的等计数通道；检验更新符号及保留集排序，并检验未来变更不影响此前预测、跨时段不配对。
- 本轮全部历史已观察，属于滚动探索性实验；不根据预测结果重选事件定义/窗口/编码/阈值。不运行收益回测，事件预警无多空方向且未证明风险高即持仓不利。原始量价口径限制沿用已有记忆。
