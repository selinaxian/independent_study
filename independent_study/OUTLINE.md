# 新研究项目大纲：金融特征、STDP表示与真实合约交易检验

用户已授权分阶段自主完成整个流程及报告。项目在independent_study独立实现，research/仅作只读流程参考，不复制其代码、参数文件、权重或研究结论。已有原始包、标准底表、旧实验保持不变。

## 阶段一：研究设计与资料核对

1. 核对原论文如何区分脉冲时机和多空方向、训练与样本外评价。
2. 阅读旧research的流程说明与问题记录，形成独立设计依据。
3. 固定数据范围、合约选择的可得时点、训练/验证/最终测试日期和交易假设。
4. 核实IC合约乘数、最小价位及手续费资料；无法确认的供应商口径明确列为假设。
5. 在观察本轮测试指标之前保存实验协议、参数及来源。

## 阶段二：真实合约数据与金融特征

1. 从data/standardized/ic_v1/contracts读取，核验哈希与合约/时间唯一性。
2. 仅使用前一日可知的流动性信息，在已有合约集合中选择交易标的，记录缺数据与跳过原因。
3. 每个合约、连续交易时段内构建候选特征，特别关注历史支撑/阻力、路径、波动、成交量与持仓变化。
4. 保存每个特征的公式、经济假说、可用时刻、零分母处理及训练期归一化参数。
5. 标签使用信号发出之后的价格；交易执行采用延迟入场，不用信号所在K线收盘价假装成交。

## 阶段三：编码与无监督STDP-SNN

1. 比较有符号双通道的随机速率编码与确定性脉冲密度编码，区分市场分钟和仿真时间步。
2. 采用可解释的竞争LIF隐藏层及因果迹式STDP，不将未来收益传入突触更新。
3. 输出隐藏神经元的发放/膜电位表示，再用训练期拟合的读出产生连续预测。
4. 保存权重、阈值、活动分布、表征差异、检查点和随机种子。
5. 配套随机突触及打乱分钟顺序的训练对照，检验学习和时序关系的作用。

## 阶段四：前瞻性预测检验

1. 主要目标为几分钟持有期的方向/收益预测；辅助检验未来波动幅度，避免把风险预警等同于多空信号。
2. 与原始特征、价格历史、随机SNN及原始特征加STDP比较。
3. 评价IC、Rank IC、误差、方向准确率、分组未来收益、种子稳定性及按日分块的不确定性。
4. 网络和读出选择仅用训练/验证期；锁定后才查看最终测试结果。
5. 报告每个阶段的样本范围与状态，保留失败或无增量的结果。

## 阶段五：实际合约上的条件回测

1. 单合约、单仓位、固定分钟持有、不跨午休和隔夜；入场与退出严格在未来可用报价上。
2. 采用合约乘数、手数、手续费、滑点与资金/保证金约束计算现金盈亏。
3. 策略阈值与是否参与交易只按验证期决定，包含空仓基线。
4. 同时报告毛收益、扣费收益、交易数量、回撤、收益波动和成本/延迟敏感性。
5. 数据调整和分钟成交假设未获供应商确认时，结果标为条件模拟，不宣称已验证可实盘盈利。

## 阶段六：报告与复现交付

报告包含：研究目标；数据格式/覆盖/缺失；特征公式与时点；编码公式与示例；网络输入、隐藏层、神经元数量与输出；STDP更新；训练与切分；预测分析；回测规则和成本；实际结果；局限及下一步。

交付配置、代码、测试、阶段记录、模型、逐样本预测、逐笔交易、净值曲线和中文总报告。主报告应能独立阅读，不依赖聊天记录。

## 完成标准

- 真正执行数据准备、训练、预测和回测，不能只交代码或大纲。
- 未来数据不参与当时特征、合约选择、STDP或最终测试调参。
- 能追溯每个预测和交易到合约、时间、输入窗口、模型及成本假设。
- 无论结果是否盈利，都给出完整且可复查的结论。
