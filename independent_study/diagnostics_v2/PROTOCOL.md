# v2：滚动训练与市场状态定位协议（2026-10-28）

用户已批准四组定位实验和滚动训练，并授权自主完成。全部选择在本轮结果生成前固定。v1核心代码、模型与结果不修改；复用其金融特征函数、编码和STDP数学机制以控制变量。4—9月已有结果暴露，本轮只称滚动历史检验，不称全新留出。

## 一、设计选择及比较边界

采用每5个原始包日期更新、此前40个有效合约日训练、随后10有效日验证的固定长度滚动窗口。每日重训更贴近原论文，但计算量和短期估计噪声更大；每月更新可能遗漏适应性，因此本轮固定约每周更新，暂不搜索窗口长度。训练和验证都严格早于预测段，旧预测永久保存，后续重训不回写历史。首段从2026-04-01开始，末段截至09-15。缺行情的包日期保持空仓，不能挪动预测边界来回避缺失。

三种训练方式：(a) frozen：首折训练/验证后完全冻结；(b) readout_only：首折特征缩放和SNN冻结，逐折只更新读出；(c) rolling_all：逐折从同种子重新初始化SNN，更新训练期缩放、神经阈值/权重和读出。rolling_all并非在线跨日承接权重，也不能把它与readout_only的差异全归因于STDP（缩放和阈值也改变）；随机突触对照帮助区分这些因素。

保持12金融特征、12分钟窗口、24符号通道、8仿真步/分钟、64竞争LIF、3轮、批128和种子104/211/307不变。金融主实验固定rate编码，避免同时改动训练频率和编码；编码保真另比较完整逐分钟脉冲计数与全窗计数。神经模式为random、stdp、shuffle（保留末分钟、打乱此前分钟，并重新训练）；固定与滚动比较使用共同样本。

## 二、四组实验

1. **已知答案时序**：生成成对AB/BA，正负两例每个通道的总脉冲数完全一致，最后3分钟输入也一致；两个间隔1/5分钟，每对随机幅度/噪声相同。按对分训练600/验证200/测试400对，避免近重复跨集合。先编码AB，再交换A/B分钟块得到BA，排除编码随机计数泄漏。比较原始完整序列、全窗计数、逐分钟计数、随机SNN、STDP和打乱SNN；线性/非线性读出相同。完整序列是有答案的正对照，计数是理论无序负对照。训练参数仍使用金融版，不根据合成测试成绩优化。
2. **信息在哪一步变弱**：raw_history144、rate_counts_by_minute288、rate_counts_total24、random192、stdp192、shuffle192、raw_plus_stdp336、risk_control2。对每条通路采用相同的读出选择流程。逐分钟计数保留分钟顺序，全窗计数刻意丢弃顺序；这一区别本身不能被称为编码损失。
3. **读出限制**：linear Ridge与256维随机傅里叶特征(RFF)加Ridge。RFF近似高斯核，属于受控非线性读出而不是新SNN训练。均值/方差、核带宽（训练样本距离中位数）只拟合训练；种子固定，容量相同；alpha格点与v1相同，各回归目标/分类组按验证误差选择。不是穷尽所有非线性模型；非线性也失败不能证明表示绝对没有信息。
4. **方向、波动与状态**：预测5分钟延迟入场收益、其绝对值、未来5分钟实现波动，以及当前/未来四类状态。当前状态识别与前瞻预测分表，不将识别当前波动当成预测未来收益。

## 三、市场状态的可操作定义

当前路径为C[t-5:t]的6个收盘；未来路径为O[t+2:t+7]的6个开盘。每条路径计算RV=sqrt(sum(log(P_i/P_(i-1))^2))*10000，效率E=abs(P_last-P_first)/sum(abs(diff(P)))，分母下限1e-8。状态编码为2×高波动+高效率：0低波震荡、1低波趋势、2高波震荡、3高波趋势。此处“趋势”是5分钟路径效率高，不表示宏观牛熊或交易方向。

波动阈值取首折训练期当前RV中位数，效率阈值取首折训练期当前E的2/3分位。阈值随后固定、当前和未来共用，保证不同训练方式/日期的标签含义一致。量化阈值只是研究定义，不是真实市场状态的权威标签。未来状态只用于训练期监督读出或事后评价，不能成为当时输入。当前标签由已有行情定义，是表示可读性的检查，本身没有新增信息；精确规则基线应为100%。未来状态基线含训练多数类、状态持续（当前状态预测未来）和原始特征读出。

读出输出3个回归值及当前/未来各4类分数（共11列）。分类使用one-hot平方损失，4列共用alpha，argmax分类；截负后归一的分数只用于Brier诊断，不宣称已校准概率。方向由收益符号评价，零收益单独报告；状态报告accuracy、balanced accuracy、macro-F1和各类支持数。

## 四、因果性、评价和交易

每折重新从未缩放的因果特征生成窗口；不通过v1已截断X反推原特征。归一化仅使用该折训练期唯一分钟，验证/预测不参与拟合。所有标签在同一半日内完成，训练/验证/预测按整日分离。每折预测前保存模型、读出、参数、日期、来源哈希和锁，先锁定再变换预测数据。

所有预先列出的对照都保留，不看4—9月结果后挑参数。回归报告Pearson/Rank IC、RMSE、月份结果；分类报告上述分数。配对5日块bootstrap、1000次；对照含STDP-random、STDP-shuffle、raw+STDP-raw，以及rolling_all-frozen/readout_only。多个探索性比较未做确认性多重检验校正。

先用原来的一手/5分钟/延迟成交/费用/滑点规则比较滚动方向信号，逐折阈值由训练预测分位和此前验证净收益决定，含空仓；最少验证交易10笔。主要策略候选限raw_history/stdp/raw_plus_stdp的线性读出，避免事后扩大赢家搜索。各模型诊断门槛和正式选择分别保存；资金跨折连续，不能每折重置100万元。成本敏感性至少基础、2tick与额外1分钟延迟，不重新挑门槛。

若只有当前状态识别较好而未来状态没有超过持续/原始基线，不新造一个STDP状态策略。若未来状态存在稳定增量，再记录依据并开展独立的探索性状态过滤实验，不能把整段事后选出的过滤法算作已锁定收益。
