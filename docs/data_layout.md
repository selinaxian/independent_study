# IC标准行情库设计

用户已同意按真实合约整理，逐日提取后在同一合约内合并。数据源为data/分钟线，第一版输出data/standardized/ic_v1，已有目录不覆盖。

## 布局

- contracts/IC年月.parquet：7种具体合约，各一份按时间排序的行情。
- continuous/ICL*.parquet：ICL0/1/2/3/8/9，各自独立；不把滚动别名当作具体合约。
- previews/*.csv：每个序列首尾各10条，方便人工查看。
- metadata/：原始包/成员索引、字段说明、合约覆盖、逐日质量、缺失、重复/冲突记录、已有主连匹配证据和运行清单。
- README.md：结果、已知限制、读取示例。

## 字段与保留原则

instrument_id标识文件中的序列；contract_id仅对具体月份合约赋值，连续序列为空。datetime以原始本地时间定位到Asia/Shanghai，交易日期取IC日盘日期；供应商开始/结束标签定义仍为unknown。保留float64价格，不做价格调整或按最小跳动单位舍入；成交量与持仓量存为非负整数。

每行有source_id、source_row，通过成员索引可追溯压缩包、内部文件、内容哈希。每个包保留格式、大小、mtime和SHA256。每次写出新版本，不覆盖旧数据。

合约+时间为唯一键。同一时间的不同合约同时保留。完全重复行保留一份并记下全部来源；同键不同值的冲突行全部写入隔离表，主表不擅自选择版本。不能解析的时间、非有限/不合法价格、非法成交量/持仓量或源日期不符的行也隔离，保留原字段及原因。

按当前观察到的09:31—11:30、13:01—15:00构建240分钟参考网格，明确只是现有时间标签假设。报告缺分钟、空文件、未提供成员及网格外时间，不填价格/成交量；未提供文件不直接判定休市或未上市。缺失表同时标明是否位于该合约已观察到的数据起止之间，避免把全部生命周期外日期当成丢失。

原主连与具体合约差异只作校验证据，不修补、不反推contract_id。已存在的审计证据仅在本次相关源文件内容与审计哈希完全一致时复制；否则标记证据不适用，避免沿用旧映射。

## 边界与验证

本轮不生成特征/未来标签、不决定交易主力规则、不改动SNN读取器或重训。多合约后续计算必须分合约及连续时段，训练/验证/测试使用统一日历边界。

验证真实合约与连续别名隔离、同时间不同合约合法、重复和冲突不静默丢弃、空文件/日期记录、价格及整数精度、时区和Parquet往返；并对照前一轮每个IC源成员的哈希/行数，核验主连与既有final.csv的一致性。固定本轮清单、配置与代码哈希以供复现。
