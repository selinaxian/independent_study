# 首版 IC 分钟 STDP 实验设计

用户已授权根据既有目标和材料自主确定细节，直至训练完成。以下为首版可替换配置，不代表已经证明的金融规律。

## 研究问题与选择

研究金融特征的先后组合是否经无监督 STDP 学习形成具有未来信息的表示。
选择10个有经济含义、当前 OHLCV/OI 可以计算的特征。仅价格变化的方案作为基线；加入盘口的方案待有新数据后扩展。
现有数据允许方法验证，合约映射和调整口径未知限制了经济结论。

## 特征与时点

决策时点为分钟结束。按上午/下午、交易日、缺分钟、已知合约变化分段，窗口不跨段。
在时点 t，R=max(H[t-20:t-1])，S=min(L[t-20:t-1])，A=mean(TR[t-20:t-1])。
TR_i=max(H_i-L_i,abs(H_i-C_{i-1}),abs(L_i-C_{i-1}))，分段首根 TR 为空。

| 特征 | 定义 | 研究含义 |
| --- | --- | --- |
| move_1 | (C_t-C_{t-1})/A | 最近价格变化 |
| move_3 | (C_t-C_{t-3})/A | 较短路径速度 |
| path_efficiency_5 | (C_t-C_{t-5})/sum(abs(diff(C)), 最近5分钟) | 持续推进或来回震荡 |
| distance_resistance | (R-C_t)/A | 接近或越过历史高点 |
| distance_support | (C_t-S)/A | 接近或跌破历史低点 |
| close_location | (2C_t-H_t-L_t)/(H_t-L_t) | 分钟内收盘位置 |
| volatility_compression | log(std(diff(C),最近5分钟)/std(diff(C),此前20分钟)) | 波动收缩或扩张 |
| relative_range | log((H_t-L_t)/A) | 当前分钟振幅相对环境 |
| relative_volume | log1p(V_t)-log1p(mean(V[t-20:t-1])) | 成交活动相对近期水平 |
| open_interest_change | (OI_t-OI_{t-1})/OI_{t-1} | 未平仓合约数量变化 |

R/S 是候选价位，不将其预设为有效支撑/阻力。持仓量变化不直接解释为净多头或资金净流入。
缺少成交额和盘口，不使用精确 VWAP、盘口不平衡或主动买卖量特征。
历史不足样本不补零；零分母一般置缺失并排除窗口。平坦路径效率、平坦分钟位置定义为0；可为0的短期波动/振幅比在取 log 前以1e-6作下限。

## 数据切分和目标

- 2026年1—3月训练，4月验证，5—6月测试；按交易日切分，不随机打散分钟。
- 输入为连续10分钟的10特征；历史尺度拟合仅使用训练期的唯一有效分钟。
- 每项用训练期绝对值99%分位数缩放、截断[-1,1]，保留正负零点含义。
- 评价目标为未来5分钟对数收盘收益（基点），仅用于读出拟合和事后评价，不进入 STDP。
- 不允许目标跨午休、隔夜、缺分钟或切分边界；未来收益不是实际成交收益。

## 编码与学习

每项正负拆为两个非负通道，共20通道；每个市场分钟10个模拟步，以最大概率0.25做 Bernoulli 离散的 Poisson 风格速率编码。
64个竞争 LIF，侧向抑制，每样本每步最多一个赢家，训练期阈值自适应。
膜电位时间常数20步，pre/post迹时间常数20步；迹可跨相邻市场分钟，不跨独立输入窗口。
STDP 增强使用当前 post×衰减的历史 pre，减弱使用当前 pre×衰减的历史 post，不计同一步配对。
突触更新随剩余上界/当前权重调制，限定[0,1]，每批归一化每个神经元入连接总量为4。
种子17/29/43，各训练3轮，仅使用训练窗口；验证测试时突触和自适应阈值均冻结。
输出为64个窗口发放率和64个末端归一化膜电位。STDP不以未来收益优化，不把输出spike固定解释为市场大事件。

机制参考已读 Gao/Luk/Weston 论文、SpikingJelly 的迹式 STDP、旧 NumPy 示例的竞争机制；采用独立 PyTorch 实现以明确时序、批量平均、冻结及零时差规则。
本实现的零时差不更新策略与当前 SpikingJelly 函数“先加当前脉冲再配对”的约定不同，已明确记录并验证更新方向；不声称原样复现论文或框架。

## 读出和对照

使用有监督 Ridge 读出检验可预测信息，属于“无监督表示+监督读出”。正则系数只按验证 MSE 选择。
对照包括常数训练均值、价格变化序列、原始最后一分钟特征、原始完整序列、冻结随机突触 SNN、STDP SNN、原始序列+STDP。
随机对照使用同一初始突触、同样训练期阈值自适应和编码随机性，仅关闭突触学习，避免把阈值校准误归因于STDP。
另检查固定末分钟、打乱前9分钟编码块后的表示；对打乱表示独立拟合读出。它只是顺序敏感性诊断，滚动特征仍含历史信息，且未重训打乱STDP网络，不宣称完整时序消融。
报告三种子各自指标和预先确定的平均预测，不用测试结果挑选种子、特征、窗口或网络。
预测指标为 IC、Rank IC、每日 IC、RMSE和方向准确率。目标重叠，不作独立分钟样本的显著性推断；不计算缺少真实合约条件下的策略 Sharpe。
